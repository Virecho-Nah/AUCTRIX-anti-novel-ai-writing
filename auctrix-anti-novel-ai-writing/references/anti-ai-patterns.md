# Anti-AI Patterns Reference

把本表用于定位风险，不把任何词机械判定为错误。最终判断标准是：表达是否提供独立信息、符合人物和场景、没有重复解释。

## 高频填充词

- 微微、缓缓、轻轻、悄然、隐隐
- 仿佛、似乎、宛如
- 带着几分、透着一丝、若有若无
- 猛地、骤然、瞬间

保留例外：速度、幅度或突然性会改变动作结果、节奏或人物状态时，应保留或改成更准确的词。

## 模板化表演

- 眼底闪过一丝……
- 嘴角勾起一抹……
- 眸光一沉／微冷
- 呼吸一滞
- 身体微僵
- 握拳、咬牙、皱眉、深呼吸连续出现

先检查是否与台词或其他动作重复。若微表情承担转折、隐瞒、认出、权力变化等功能，保留最有效的一项。

## 功能性细节链

细节密集不等于 AI 味。连续描写若让画面状态或观众认知逐步变化，应视为功能性细节链，而不是动作堆叠。

常见结构包括：

- 误认 → 异常 → 揭示
- 静止 → 苏醒 → 爆发 → 审视
- 局部 → 全貌 → 尺度对比
- 看见 → 辨认 → 锁定目标
- 犹豫 → 决定 → 执行动作

压缩前，为每一行写出它的独立功能。若两行功能不同，不得只因主体相同、词语相近或副词集中而合并。尤其不要把“过程”清洗成一句直接结论，否则会丢失悬念、节奏或表演空间。

例如，“缓慢起伏—猛地睁开—轻微转动—锁定角色”依次表现苏醒、突发揭示、审视和选择目标。四个状态不是同义重复；只能清理局部措辞，不能压成“眼睛睁开并锁定角色”。

## 作者总结句

- 这一刻……
- 直到此刻……
- 她终于意识到……
- 她不知道的是……
- 从这一刻开始……
- 命运的齿轮……
- 这意味着……

若结论已经由现有画面或台词清楚表达，删除总结。若它包含画面没有提供的必要信息，保留或标记确认，不自行设计证据。

## 假影视化

- 镜头缓缓推进／掠过／扫过
- 镜头定格
- 慢镜头
- 压迫感、危险感、宿命感笼罩画面

运镜词本身不是错误。问题在于它是否说明了观众实际看到什么，以及是否符合当前文本格式。不要通过加入运镜掩盖抽象表达，也不要为了“真实画面”凭空补写环境。

## 解释型句式

- 不是……而是……
- 没有……没有……没有……
- 之所以……是因为……
- 与其说……不如说……

这类结构可能是 AI 痕迹，也可能是角色语言习惯或有意强调。仅在逻辑重复、所有角色同声同气或台词过度自我解释时压缩。

## 括号内高风险标注

- 带着几分复杂
- 压抑着某种情绪
- 强忍着内心波动
- 眼底闪过复杂情绪
- 连自己都不愿承认地……

优先保留能改变演法的一个信号，如停顿、低声、冷笑、苦笑、哽咽、看向某人。若台词本身没有唯一演法，不要仅因标注是情绪词就删除。

## 功能检查

每次删除前确认：

1. 删除后事实是否不变？
2. 删除后人物关系和情绪转折是否仍清楚？
3. 是否在用另一个模板词替换原模板词？
4. 改写是否新增了原文没有的行为或物件？
5. 同一个词换到另一角色身上是否仍成立？若成立，可能缺乏人物特异性。
6. 删除后是否跳过了观众原本逐步发现真相的过程？若是，恢复细节链。
